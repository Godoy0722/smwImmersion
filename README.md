# SMW Immersion Theme

An OJS theme developed by the journal Swiss Medical Weekly, based on Immersion.

## Requirements

This is a **child theme** of the [Immersion theme](https://github.com/pkp/immersion).
The parent Immersion theme **must be installed and present** in the OJS plugin
registry; otherwise this theme will refuse to register its styles, templates and
hooks and an admin notice will be shown on the Website Settings page.

Install order:

1. Install and verify the Immersion theme.
2. Install this theme.
3. Activate "SMW Theme" under *Settings → Website → Appearance → Theme*.

Compatible with OJS 3.5.0-x
